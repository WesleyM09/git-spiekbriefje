# Spiekbrief Git en GitHub
## 1. Clone, commit, push en pull

Clone: Je maakt een lokale kopie van een project uit een online repository (bijvoorbeeld GitHub).

Commit: Je slaat je wijzigingen lokaal op met een korte beschrijving van wat je hebt aangepast.

Push: Je stuurt je lokale wijzigingen naar de online repository.

Pull: Je haalt de nieuwste wijzigingen van de online repository op naar je eigen computer.
