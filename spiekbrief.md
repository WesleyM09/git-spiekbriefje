# Spiekbrief Git en GitHub
## 1. Clone, commit, push en pull

Spiekbrief: Clone: Je maakt een lokale kopie van een project uit een online repository.

Spiekbrief: Commit: Je slaat je wijzigingen lokaal op met een korte beschrijving van wat je hebt aangepast.

Spiekbrief: Push: Je stuurt je lokale wijzigingen naar de online repository.

Spiekbrief: Pull: Je haalt de nieuwste wijzigingen van de online repository op naar je eigen computer.



## 3. Gitignore

Spiekbrief: Een .gitignore-bestand zorgt ervoor dat Git bepaalde bestanden en mappen niet bijhoudt in je repository.

## 4. Pull

Spiekbrief: Een pull neemt gewijzigde elementen die niet in VS Code zijn aangepast op en slaat ze op. Hierdoor kun je altijd een overzicht blijven houden hoe alles verloopt zonder een fout op te lopen.
